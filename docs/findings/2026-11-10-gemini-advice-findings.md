## Checks that affect these dispositions

These are algebra and source checks, not new fitted experiments.

**Weighting is not settled by S-13.** Write G for expected reconstruction log likelihood and K_L, K_F, K_β for positive KL terms. The current survival-block option optimizes G − K_L − K_F + w(S − K_β). Dividing by w gives G/w − K_L/w − K_F/w + S − K_β. The specifications propose κ(G − K_F) − K_L + S − K_β. Even at κ = 1/w, the L penalty differs. Without tempering F KL too, that penalty differs as well. The V1 learning rate uses N_event/n, while V2 uses N_event. A proposed comparison must settle this factor n. Keeping Cox weight one does not guarantee coverage with estimated loadings, selected programs, an empirical prior and a local quadratic approximation.

**Constant feature-count weights do not guarantee bounded scores.** In general Var(Yf) = f′Cov(Y)f, which includes cross-feature covariance. The specifications' O(1) argument omits those terms. For p identical unit-variance columns and f_j = 1, Var(Yf/√p) = p, not 1. Nor does unit feature variance imply that nonnegative factor loading RMS is at most one when input means can be large. The proposed constants remain candidates for D, not proofs of balance.

**A τ bound is an additional model constraint.** The implemented MLE is n/Q_j, so large expected residual energy can lower τ. A Gamma posterior mean also tends to zero as Q_j grows. A fixed positive lower bound removes that route, but standardized observed sample variance does not prove a universal residual bound for an imperfect fitted reconstruction. Frozen τ and bounded adaptive τ have different targets and must be judged separately. V2's stated lower precision for F additionally assumes canonical E[L²] has been fixed at one. That is not the current unit-score-SD convention.

**The inverse-Gamma formula is not the stated MAP update.** Under density p(v) ∝ v^(−a−1) exp(−b/v), a Normal coefficient contributes −½ log v − E[β²]/(2v). The maximizing variance is (b + E[β²]/2)/(a + 3/2). The specifications instead use denominator a + 1/2. A differently defined hyperprior could give a different formula, but it must be written explicitly. Its log density is also missing from the supplied monitored objectives. Scaling a prior variance preserves a Normal KL under a pushforward. It does not preserve a fixed inverse-Gamma hyperprior penalty unless that model is transformed as well.

**KL must refer to the stored distribution.** V1's F code damps moments, then computes KL from a newly solved posterior without replacing those stored moments. Its L code similarly resolves q after changing g but stores the earlier moments. V2 refits all genes at pseudo-observations collected during a sequential pass. That vector refit changes q and is not the fixed-q maximization claimed in the text. Neither supplied outer loop implements the promised full objective acceptance/backtracking. V2 stops when either the ELBO change or η change is small, although reconstruction or posterior uncertainty may still move. Its `rho_r` multiplies only F's survival terms, and changes during the ramp, while its monitor has no matching ρ and β uses full survival weight. Thus it is not coordinate ascent on the stated single objective. The current derivation already warns that re-expanded Taylor monitors and prior refits need not be monotone.

**Canonical rescaling and a changing model denominator are different operations.** The current canonical loop uses YF directly and applies F_k/c_k, c_kL_k and c_kβ_k together. For joint β it also multiplies covariance element kl by c_kc_l and prior variance k by c_k². This is already the covariance transformation sought in V2, using the opposite convention for c. A held/shared prior, absolute floor or stopping criterion still needs explicit checking. The screenshot diagnosis alone does not establish that rescaling causes the historical caps.

**Prediction must retain its training contract.** Both specifications recompute projection weights from the number of measured test features. This changes the relative modality contributions when coverage differs. V2 also clips the centered training η for Cox working quantities, which evaluates a modified predictor rather than the unclipped likelihood. Its orientation calculation ignores strata. These are reasons to retain the current predictor and arithmetic helpers. Changing signs for historical reporting is distinct from modifying fitted coefficients. Donor grouping is already implemented and does not require deleting repeated assay records.

## Ideas worth acting on

1. **D: test scale invariance and modality balance.** Carry all held priors, covariance and KL terms through rescaling. Derive any modality weights from one objective and check correlated-feature behavior.
2. **ROADMAP: a coherent PE fixed-q prior update.** This fills a real gap in the current option, which supports point-Laplace only. Pursue it if A exposes convergence failures, without changing A's arms mid-comparison.
3. **ROADMAP: anchored or bounded residual precision.** Keep the existing fixed-τ result as a control, and distinguish bounded adaptation from the already tested fixed case.
4. **ROADMAP: genomics tempering with Cox weight one.** S-13 did not test this exact objective. Settle every KL weight and the factor n before a registered comparison.
5. **ROADMAP: regularized nonzero β variance and paired positive/negative Cox starts.** These are conditional follow-ups to documented collapse, with corrected hyperprior algebra and separate evaluations after the fixed A/B comparisons.
6. **Existing tasks: finish the planned prior/PIP, cohort-noise and biological checks.** A/B retain the nonnegative and sparse-prior ideas. D and the existing per-cohort τ and biology items retain information that concordance alone would miss.
