Executive summary

In one line: the multimodal model now works as intended in simulation. It recovers the true programs and picks the right number of them.

On matched TCGA → ICGC data its best result matches our established single-modality model (C = 0.685 on the same 50 donors). Across starting ranks, though, external C is typically lower (median 0.57). Methylation has not yet added predictive value.

The main open problem is that on real data the model does not yet choose its own number of programs.

Three questions, three answers

Question Short answer Evidence
1. Is the multimodal model implemented correctly, and can we trust it? Yes, at the level of the code and in simulation. 531 unit tests pass. The posterior updates match ebnm to \(10^{-6}\), and the compiled updates match R to \(10^{-14}\). In 486 simulated fits, the recommended configuration recovers the true programs at moderate noise, converges every time, and returns the true number of factors whatever the starting rank (§1).
2. What value does it add over the single-modality model? No performance gain yet, and no new prognostic information. At the pre-specified starting rank it equals the established model (0.685 vs 0.685). Across starting ranks the median is 0.57. Its prognostic program is the same basal-like axis as single-modality Program 7 (§2).
3. What does methylation contribute? Interpretable structure, not prediction, so far. Adding methylation changes external C by +0.01. Most of the methylation signal goes to an immune program and a methylation-only program, neither prognostic. Most expression programs barely change (§3).

Open problems, for discussion

  1. Choosing the number of programs on real data.
    • Pruning removed no factors at any starting rank (3–15), so the starting rank fixes the final rank, and results vary with it.
    • The reason: with 144 × 13,000 values, reconstruction outweighs survival by about \(10^4\) to 1 in the evidence used for pruning.
    • Proposed next step: weight the two modalities and survival (§4).
  2. How to get more from methylation. Screen CpGs tied to the selected genes, such as promoter CpGs, instead of the 10,000 most variable (§3).
  3. A low-variance prognostic program is still missed in simulation at moderate noise. This is the same question as α_F in the single-modality model (§4, §8).

10.1 §1 — Is the model correct? Implementation checks and simulation

The configuration we recommend. The pruned fit has four parts:

  • a per-feature intercept, so loadings describe deviation from each gene’s or CpG’s baseline;
  • signed point-Laplace loadings;
  • empirical-Bayes priors fit by marginal likelihood;
  • an evidence check (the “nullcheck”) that removes any factor the evidence lower bound (ELBO) prefers to drop.

What it is compared against.

  • Original fit. The September implementation: no intercept, nonnegative loadings, and no pruning.
  • Variance-corrected pruned fit. The same as the pruned fit, except the survival term in the ELBO subtracts a variance penalty. It gave results identical to the pruned fit in every summary, so the simpler version is kept.

Implementation checks.

  • The full test suite passes: 531 tests.
  • The signed-prior posteriors match ebnm with the prior held fixed, to \(10^{-6}\).
  • The prior fits recover known parameters.
  • The KL terms match closed forms.
  • The compiled loading sweep reproduces the R version to \(10^{-14}\); on TCGA, the loadings agree to \(5\times10^{-16}\).
  • The 35 algebra checks in derivations/multimodal_YFB/verify_derivation.R pass.

Simulation.

  • Design. True \(K=3\), \(n=120\), 50 + 50 features.
  • Grid. Three scenarios × two noise levels × starting ranks 3–10 and 15 × three seeds: 486 fits, none of which errored.

10.2 §2 — What value does it add over the single-modality model?

External discrimination: parity at best. Models were trained on TCGA (144 patients) and validated on ICGC primary PDAC (50 donors, 30 deaths). All 50 donors are also in the PACA-AU RNA-seq cohort used to validate the single-modality model.

Multimodal, pruned fit, expression only, \(K_{\mathrm{init}}=7\) TCGA 0.676 (0.569–0.770)

But the result depends on the starting rank. Pruning removed nothing on real data, so each starting rank is also the final rank:

  • Across starting ranks 3–15, external C has a median of 0.57 (range 0.50–0.685).
  • At a starting rank of 5, no program is survival-active, so the risk score is constant (C = 0.5).
  • At 15, eleven of fifteen programs are survival-active, and C falls to 0.547. The extra survival associations do not hold out of sample.

Information. The one survival-active program at \(K_{\mathrm{init}}=7\) is the basal-like vs classical axis. It is strongly prognostic in ICGC (HR 1.99 per SD, \(p=0.0003\)). It corresponds to single-modality Program 7 (\(\lvert r\rvert=0.68\)), which the single-modality model already finds. The multimodal model therefore reproduces the known prognostic structure but has not yet found new prognostic programs.

10.3 §3 — What does methylation contribute?

To prediction: +0.01. Expression + methylation reaches 0.685 and expression alone 0.676 under the same framework, well within the uncertainty for 50 donors.

To structure: an immune program and a methylation-only program.

  • Methylation share is each program’s share of the fitted methylation signal, \(\lVert L_k\rVert^2\lVert F_{\mathrm{meth},k}\rVert^2\).
  • The methylation-only program carries 59% of the methylation signal.
  • The immune program carries 21%, with strong loadings in both genes and CpGs.
  • The exocrine program carries 9%.
  • The prognostic basal-like program carries 4.5%.

Most expression programs barely change when methylation is added.

  • Four of the six expression-loading programs match the expression-only fit at \(\lvert r\rvert\) 0.79–0.91, including the prognostic program at 0.88.
  • The immune (0.67) and stromal (0.52) programs change more. These are where methylation adds structure.

Interpretation, and the next experiment.

  • At the current screening (the 10,000 most variable CpGs), methylation appears to record mainly cell composition, especially immune content, rather than tumor-intrinsic prognostic programs.
  • The natural next test is to choose CpGs for their link to the selected genes, such as promoter CpGs of those genes. That would ask more directly how methylation can add information.

10.4 §4 — Open problems and proposed next steps

1. Choosing the number of programs on real data (top priority).

  • Why nothing is pruned. The nullcheck keeps a factor when removing it lowers the evidence.
    • On TCGA every factor’s reconstruction gain (\(10^4\)–\(10^5\) nats) far exceeds its KL cost.
    • Survival changes the evidence for any factor by less than 3 nats: there are 75 events against about 1.9 million reconstruction terms.
    • So the evidence supports many molecular factors, as unsupervised factorization does (flash keeps 14 on expression alone). Survival has no say in which factors are kept.
  • Proposal: weight the likelihood. Put weights \(w_{\mathrm{expr}}\), \(w_{\mathrm{meth}}\) and \(w_{\mathrm{surv}}\) on the expression, methylation and survival terms. Scaling all three together mainly changes posterior width. Two ratios matter, so tuning is a two-dimensional surface:
    • methylation vs expression, which balances the modalities;
    • survival vs reconstruction, which sets how much survival shapes which factors are kept.
  • Plan.
    1. Start from principled defaults. For example, weight each modality by \(1/p_m\) so each counts equally, and put survival on the scale of one modality.
    2. Map a small grid of the two ratios, scored by simulation recovery and held-out C, to show sensitivity.
    3. Test whether stronger survival weight lets the model prune on real data and recover the low-variance prognostic program in simulation.

2. Getting more information from methylation. Gene-linked CpG screening (§3). Also consider survival-aware screening, and the arcsine scale for methylation (§7).

3. Smaller items.

  • Stopping rule. Stop on the ELBO or the mean change, and run the nullcheck only on converged fits. Most real-data fits reached the 500-sweep cap with a stable risk score.
  • False positives. Reduce false survival-active factors and survival-only duplicates.
  • Attribution. Identify which part of the framework is responsible for its real-data gain over the original fit: the intercept, the signed loadings, or pruning.

4. Single-modality model. Run the α/α_F experiments (§8). The weighting proposal above is the multimodal form of the same question.

10.5 §5 — Supporting detail: the multimodal model

The base update equations are in derivations/multimodal_YFB/multimodal_YFB_derivation.pdf. The intercept, signed priors, ELBO and pruning are documented in DECISIONS.md (2026-10-01) and code/fit_multimodal_yfb.R. They will be added to the derivation.

Reconstruction. Scores are shared; each modality has its own loadings and baseline:

\[ Y_m = \mathbf 1\mu_m^\top + L F_m^\top + E_m,\qquad E_{mij}\sim N(0,\tau_{mj}^{-1}),\qquad m=1,2. \]

  • \(L\ge0\) is program activity per patient. \(F_m\) is how far each gene or CpG moves from its baseline \(\mu_{mj}\) when the program is active.
  • \(\mu_m\) is re-estimated every sweep.
  • Each feature has its own residual precision \(\tau_{mj}\), estimated by maximum likelihood without regularization.

Survival. A Cox model with \(\boldsymbol\eta = (Y_1F_1+Y_2F_2)\,\beta\). A new patient’s risk needs only their measurements and the fitted \(F\) and \(\beta\). Survival enters the \(F\) and \(\beta\) updates, and the \(\beta\) update uses \(E[Z^2]\), which corrects for the attenuation that comes from treating estimated scores as fixed. A constant shift in \(\eta\) does not change the partial likelihood, so the intercept leaves survival unchanged.

Priors. Empirical Bayes throughout.

  • Scores: point-exponential.
  • Loadings: the family is chosen per modality (point-exponential, point-Laplace or Normal). Its parameters are fit for each modality–program pair.
  • Survival coefficients: \(\beta_k\sim N(0,s^2_{\beta_k})\) with \(s^2_{\beta_k}=\max(0,x_k^2-1/A_k)\). A weak program therefore gets \(\beta_k=0\) exactly.
  • Survival-active means \(|E\beta_k|/\mathrm{SD}(\beta_k)\ge1.96\).

Fitting.

  • Coordinate-ascent variational inference, with a Cox working approximation refreshed every sweep and no tempering weights.
  • Each program is rescaled to \(\mathrm{sd}(Z_{\cdot k})=1\) because its scale is not identified.
  • Nullcheck. When the sweep loop ends, remove the factor whose removal does not lower \(\text{ELBO} = E_q\log p(Y\mid\cdot) + \log PL(E[\eta]) - \sum\mathrm{KL}(q\Vert g)\), then refit and repeat. The other factors are held fixed during the check; \(\mu\) and \(\tau\) are re-estimated.

Why spare factors used to survive.

  1. Without an intercept, a spare factor could fit one feature exactly. Its precision then went to about \(10^{16}\) (true values ≤ 2.6), which gave an unbounded likelihood gain. Adding the intercept removed this.
  2. Nonnegative factors absorbed per-feature means.
  3. In the September simulations each true factor explained about 0.7% of variance, below the 1% “active” cutoff. That design could not show the problem.

Precision models tested and not adopted.

  • One \(\tau\) per modality mis-weights heteroscedastic features: no pruning, and C fell to 0.65.
  • An empirical-Bayes Gamma prior on \(\tau\) learned a heavy tail, and \(\tau\) still reached about \(10^{17}\).

10.8 §8 — Supporting detail: single-modality \(Z_F\) and the α_F question

The projection score. The β derivation (derivations/cox_on_YF/qBeta/qBeta_YF_derivation.pdf) now defines

\[ Z_F=Y\,E[F],\qquad (z_F)_{ik}=\sum_j y_{ij}E[f_{jk}]. \]

  • It is the expression profile projected onto each program’s loadings.
  • \(L\) appears only in the reconstruction; \(Z_F\) appears only in the Cox predictor.
  • The code normalizes the loading columns, \(\hat Z_F=YE[F]D^{-1}\). This changes only the units of \(\tilde\beta\).
  • Within an iteration \(\hat Z_F\) is held fixed, so there is no attenuation correction. The multimodal model has one.

α and α_F.

  • α = 0.5 tempers the Cox term in the β update.
  • α_F = 0 keeps survival out of the F update, so F is the same as in unsupervised factorization. The model therefore keeps high-variance programs that are also prognostic, and cannot find a low-variance prognostic program.
  • In early versions, α_F > 0 started an F–L feedback loop that ended in collapse. Under the current preprocessing that no longer happens, but α_F > 0 did not improve C either:
α_F 0 0.1 0.3 0.5
Mean external C 0.6267 0.6268 0.6263 0.607
# Candidate Mechanism Changes the model?
1 Factor rescaling with α = α_F = 1 Pins each factor’s scale, as in the multimodal model No
2 Warm start from the α_F = 0 fit Avoids the initialization imbalance No
3 Increase α_F gradually from 0 to 1 Optimization device; the final objective is the plain sum No
4 Reorder the updates Limits each step of the coupled L–F–β system No
5 α as a likelihood power with a stated rule Tempered posterior Yes (fallback)

Test, fixed in advance.

  • Simulation. Plant a low-variance prognostic program. Success is recovering it (\(\lvert r\rvert\ge0.7\)) and finding it survival-active more often than the α_F = 0 fit does.
  • Real data. Pooled ΔC against 0.627.
  • If supervision does not change F, we report that.
  • Speed. With survival in F, exact updates go one feature at a time. A block update over a whole column, with the coupling bounded by a diagonal term, would restore speed.
